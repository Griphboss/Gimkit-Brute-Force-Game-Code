# Gimkit-Brute-Force-Game-Code
## This bookmarklet/js script uses javascript to brute force a random game code on gimkit.


### How to Set Up
Option 1 (Recommended) - **Bookmarklet**
1. Open the bookmarklet.js file.
2. Copy all of its contents.
3. Create a new bookmark.
4. Press "*Done*".
5. Go to edit the bookmark.
6. Name it to whatever name of your choosing (ex: Gimkit Brute Force)
7. Delete the text in the URL section.
8. Paste in the code that you copied from bookmarklet.js.

Option 2 - **Console**
1. Copy the code from console.js.
2. Go to the Gimkit join page.
3. Press Ctrl+Shift+I
4. Go to console.
5. Paste in the code you copied and press Enter.

### How to Use
With Bookmarklet:
1. Go to the Gimkit join page.
2. Click on the bookmark and wait. The process could take up to 10 seconds.
3. Once you see a code, remember it.
4. Press "Ok"
5. Type in the code and press join!
Option 2 - **Console**
1. Copy the code from console.js.
2. Go to the Gimkit join page.
3. Press Ctrl+Shift+I
4. Go to console.
5. Paste in the code you copied and press Enter.

### Frequent Issues (How to Fix)
"I can't see the bookmarklet!" - Go into settings and set your favorites bar to show **Always**
